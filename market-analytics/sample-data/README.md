# Sample Data

All files here are **synthetic**: random brands (`Acne Brand 01` ...), fake IDs
(`SAMPLE00001`, `9000000000`), invented prices and made-up anchor points. They exist so the
scripts and rewritten notebooks run end-to-end. Nothing here describes a real market.
